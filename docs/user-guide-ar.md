# دليل مستخدم PharmaOS — نسخة الصيدلية

> دليل عملي مختصر. تفاصيل النسخ الاحتياطي والاسترجاع الكاملة في: **backup-restore-guide-ar.md**.

---

## 1) التشغيل

1. شغّل الجهاز وافتح أيقونة **PharmaOS** على سطح المكتب.
2. النظام يعمل بقاعدة بيانات محلية على نفس الجهاز — **لا يحتاج إنترنت للعمل** (الإنترنت فقط للنسخ السحابي الاختياري وخدمات الجهات).
3. أول مرة فقط: معالج الإعداد — ينشئ مدير النظام (super_admin) بكلمة مرور قوية تختارها أنت. **لا يوجد حساب جاهز بكلمة مرور معروفة.**
4. إذا لم يفتح البرنامج: صوّر أي رسالة خطأ، وأرسل للدعم ملف السجل: `C:\ProgramData\PharmaOS\logs\pharmaos.log` (يبقى آخر 10 ميجابايت تلقائياً مع نسخة قديمة `.old`).

## 2) البيع (نقطة البيع POS)

1. افتح شاشة البيع، وامسح الباركود بالقارئ أو ابحث بالاسم العربي (يتحمل الأخطاء الإملائية البسيطة).
2. غيّر وحدة البيع إن احتجت (علبة/شريط/قرص) — التحويل لأصغر وحدة يتم داخلياً تلقائياً.
3. الكميات الجزئية مسموحة (نصف شريط مثلاً) ويُخصم المخزون بدقة على مستوى القرص/العلبة.
4. أكّد الدفع: نقداً (يحسب الباقي تلقائياً) أو بطاقة. الفاتورة تُحفظ **كمعاملة واحدة**: إما تكتمل مع خصم المخزون معاً، أو لا تُحفظ إطلاقاً — لا وجود لحالة "نصف فاتورة".
5. **لا يمكن بيع صنف منتهي صلاحيته أو محجوز** — النظام يرفض ويوضح السبب.
6. الأصناف التي تتطلب وصفة لا تُصرف بدون ربط وصفة صالحة، ويُقيَّد الصرف في سجلها.

## 3) الجرد والمخزون

- **الاستلام**: سجّل كل دفعة (رقم تشغيلة، صلاحية، كمية، سعر شراء) — يتولد سجل حركة لكل تغيير.
- **تنبيهات الصلاحية**: قائمة مقسّمة — ينتهي خلال **30 يوماً (حرج) / 60 / 90**، والمستهلك فعلاً يُحجز تلقائياً عن البيع. راجعها **أسبوعياً**.
- **الجرد الفعلي**: قارن الكميات الحقيقية بالنظام؛ أي تصحيح يمر بسجل الحركات ولا يغيّر الأرقام بصمت. النظام يكشف انحراف كاش المخزون ويعالجه تلقائياً.
- **تحديث الأسعار والأصناف الجديدة**: ملف Excel/CSV بالأعمدة الموثقة يُستورد بأمر واحد؛ الجديد يُضاف، والموجود يُحدَّث سعره مع تسجيل القديم→الجديد ومصدر السعر (راجع الدليل الفني).

## 4) النسخ الاحتياطي والاسترجاع (ملخص)

- نسخة تلقائية **يومياً 2:00 فجراً**، مشفّرة، تُحفظ على الجهاز (آخر 14 نسخة) ومع كل نسخة ملف فحص سلامة.
- انقل نسخة إلى فلاشة **أسبوعياً**، واحتفظ بمفتاح الاسترجاع خارج الصيدلية.
- خطوات الاسترجاع وجهاز جديد: **backup-restore-guide-ar.md**.

## 5) إذا انقطعت الكهرباء فجأة

- عند عودة التيار: شغّل الجهاز وافتح PharmaOS كالمعتاد — **لا تتخذ أي إجراء آخر**؛ قاعدة البيانات تُصلح نفسها تلقائياً عند الإقلاع.
- آخر عملية بيع: إما اكتملت قبل الانقطاع (ستجدها كاملة) أو اختفت بالكامل مع مخزونها — لا يحدث تلف أو عدم اتساق. (مُتحقَّق بـ50 اختبار انقطاع عنيف).
- إن ظهرت رسالة خطأ عند الفتح: **لا تحذف أي ملفات** — صوّرها واتصل بالدعم.
- أسوأ حالة (تلف القرص): جهاز آخر + مفتاح الاسترجاع من الورقة + آخر نسخة احتياطية = كل بياناتك حتى لحظتها.

## 6) حدود النظام — مسؤولية الصيدلي

يساعد PharmaOS في إدارة الأصناف والمخزون والدفعات والمبيعات والمرتجعات والتقارير
والنسخ الاحتياطية، لكنه لا يستبدل المراجعة المهنية للصيدلي.

**تنبيه صريح:** النظام لا يفحص التداخلات الدوائية ولا يقرأ الوصفات عبر OCR.
مسؤولية التحقق من التداخلات وصحة الوصفة وشروط صرفها على الصيدلي.

عند الشك، أوقف البيع وراجع الوصفة والمراجع الدوائية المعتمدة قبل الصرف.

## 7) الصلاحيات وسجل التعديلات

- ثلاثة أدوار: **مدير** (كل شيء)، **صيدلي** (بيع + مخزون، دون إعدادات/مستخدمين)، **كاشير** (بيع فقط).
- القيود مفروضة في **الخادم نفسه** لا في الشاشة — أي طلب غير مصرح يُرفض ولو أُرسل خارج الواجهة.
- **سجل التعديلات (Audit Log)** يوثّق لكل عملية: من، ماذا، متى، والقيمة قبل/بعد — ومحمي على مستوى قاعدة البيانات: لا أحد (ولا حتى المدير عبر البرنامج) يعدّله أو يحذفه.

## 8) مفتاح النسخ الاحتياطي

عند أول تشغيل يعرض النظام مفتاح الاستعادة مرة واحدة. يجب تصديره وحفظه خارج جهاز
الصيدلية، في ظرف أو مخزن آمن منفصل. فقدان الجهاز أو إعادة تثبيت Windows مع فقدان
هذا المفتاح يعني أن النسخ المشفرة لا يمكن فكها.

لا تضع المفتاح في البريد أو مستودع المشروع أو سطر أوامر محفوظ. يجب إجراء تدريب
استعادة على جهاز آخر بالمفتاح المحفوظ قبل الاعتماد على النظام.
